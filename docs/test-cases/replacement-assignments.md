# Ручное тестирование назначения подменного автомобиля

## Назначение документа

Документ содержит ручные тест-кейсы для проверки функции назначения
подменного автомобиля водителю в рамках пользовательской истории FLEET-12.

Тестируемый endpoint:

POST /replacement-assignments

Версия: 0.2.0

---

## TC-RA-001. Успешное назначение доступного автомобиля

### Предусловия

- приложение FleetControl запущено;
- PostgreSQL доступен;
- водитель с `id = 1` существует;
- автомобиль с `id = 3` существует;
- автомобиль имеет статус `AVAILABLE`;
- активного назначения для автомобиля нет.

### Шаги

1. Отправить POST-запрос на `/replacement-assignments`.
2. Передать:

```json
{
  "driver_id": 1,
  "vehicle_id": 3
}
